# Customer Support AI Agent

A customer support AI agent built with Python and OpenAI's GPT models to provide automated customer support solutions.

## Features

- AI-powered customer support responses
- Integration with OpenAI's GPT models
- Environment-based configuration
- Modular architecture for easy extension

## Setup

1. Clone the repository:
```bash
git clone https://github.com/Shashank-KVS/cs-ai-agent.git
```

2. Create and activate a virtual environment:
```bash
python -m venv .venv
source .venv/bin/activate  # On macOS/Linux
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Configure your environment:
- Copy `config.py` to your local environment
- Set up your OpenAI API keys in the configuration
